01 — DESIGN

Первый стенд: MLflow + PostgreSQL + локальные артефакты

MLflow Tracking Server использует PostgreSQL как backend store. Файлы моделей хранятся на локальном диске, подключённом к контейнеру через bind mount. Клиент обращается к серверу по HTTP; сервер проксирует операции с артефактами.

02 — PREREQUISITES

Что понадобится

Windows 11, Docker Desktop с Docker Compose, Python 3.11+ и PowerShell.

  • Docker Engine и Compose plugin
  • Python virtual environment
  • Порты 5000 (MLflow UI) и 5432 (PostgreSQL внутри сети Compose)
03 — DEPLOYMENT

Запуск инфраструктуры

Создай каталог проекта, добавь Dockerfile и docker-compose.yml, затем собери и запусти сервисы.

docker-compose.yml · CORE SERVICES
services:
  postgres:
    image: postgres:17
    environment:
      POSTGRES_DB: mlflow
      POSTGRES_USER: mlflow
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U mlflow -d mlflow"]
      interval: 5s
      timeout: 5s
      retries: 10

  mlflow:
    build: .
    depends_on:
      postgres:
        condition: service_healthy
    ports:
      - "127.0.0.1:5000:5000"
    environment:
      MLFLOW_BACKEND_STORE_URI: ${MLFLOW_BACKEND_STORE_URI}
    volumes:
      - ./mlflow-data/artifacts:/mlflow/artifacts
    command: >
      sh -c 'mlflow db upgrade "$$MLFLOW_BACKEND_STORE_URI" &&
      exec mlflow server --host 0.0.0.0 --port 5000
      --backend-store-uri "$$MLFLOW_BACKEND_STORE_URI"
      --artifacts-destination /mlflow/artifacts'
