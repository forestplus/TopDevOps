Windows: диагностика системы из командной строки

Быстрые проверки сети, процессов и системных файлов без графического интерфейса

С чего начать

Откройте командную строку от имени администратора: нажмите Win, введите cmd, выберите «Запуск от имени администратора». Большинство команды ниже работают и без прав администратора, но команды для восстановления системы требуют их обязательно.

Порядок простой: сначала понять, что сломано (сеть, процесс, диск или системные файлы), затем проверить конкретную часть и только потом что-то менять.

Процессы

Чтобы найти процесс по имени и узнать его PID, используйте фильтр:

tasklist /FI "IMAGENAME eq notepad.exe"

Если программа зависла, завершите её по имени образа или по PID:

taskkill /IM notepad.exe /F
taskkill /PID 4312 /F

Ключ /F принудительно завершает процесс без сохранения данных, поэтому используйте его только когда обычное завершение не помогает.

Системные файлы

Если Windows ведёт себя странно, а причина неясна, сначала проверьте целостность образа системы, затем файлов:

DISM /Online /Cleanup-Image /CheckHealth
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow

Порядок важен: sfc берёт эталонные файлы из хранилища компонентов, поэтому сначала стоит восстановить само хранилище через DISM. Перезагрузите компьютер после завершения.

Диски

ЗадачаКоманда
Проверить диск на ошибки без исправленияchkdsk C:
Проверить и исправить ошибки (диск должен быть не занят)chkdsk C: /f
Посмотреть список дисков и разделовdiskpart, затем list disk и list volume
Оценить фрагментацию без дефрагментацииdefrag C: /A

Команда chkdsk C: /f для системного диска попросит перезагрузку, так как диск занят самой системой.

Версия и состояние системы

systeminfo | findstr /B /C:"Версия ОС" /C:"Время загрузки системы"
winver

Если нужны более подробные данные в PowerShell, используйте CIM-командлеты вместо устаревшей утилиты wmic:

Get-CimInstance Win32_OperatingSystem | Select-Object Caption, Version, LastBootUpTime
Перед сложными действиями (чистка реестра, изменение политик, форматирование) создайте точку восстановления или резервную копию. Команды из этой статьи безопасны для чтения, но chkdsk /f, taskkill /F и изменения сети могут прервать работу.

Памятка

  • Сначала диагностика (ipconfig, tasklist, systeminfo), потом исправление.
  • Для восстановления системы: DISM, затем sfc, затем перезагрузка.
  • Для сетевых проблем проверяйте по слоям: адрес, шлюз, DNS, маршрут.
