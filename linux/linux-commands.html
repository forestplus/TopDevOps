Лайфхаки и трюки

  1. Повторить прошлую команду. !! вставляет предыдущую команду, например sudo !!, если забыли sudo. !$ подставляет последний аргумент предыдущей команды.
  2. Поиск по истории. Нажмите Ctrl+R и начните вводить часть команды. Повторное нажатие листает совпадения.
  3. Редактировать длинную команду в редакторе. Ctrl+X затем Ctrl+E открывает текущую строку в $EDITOR.
  4. Вернуться в предыдущую папку. cd - переключает на предыдущий каталог.
  5. Следить за изменением вывода. watch -n 2 'df -h /' обновляет команду каждые две секунды.
  6. Отправить процесс в фон и вернуть. Ctrl+Z приостанавливает, bg продолжает в фоне, fg возвращает на передний план.
  7. Не потерять сессию при обрыве SSH. Запускайте долгие задачи в tmux или screen, либо через nohup.
  8. Пробросить удалённый порт на локальную машину. ssh -L 8080:localhost:80 user@server открывает удалённый сервис на вашем localhost:8080.
  9. Найти самые тяжёлые папки. du -h --max-depth=1 / 2>/dev/null | sort -h | tail.
  10. Безопасная проверка перед удалением. Сначала выполните find ... -print, и только потом замените -print на -delete.
  11. Красивая таблица из колонок. mount | column -t выравнивает вывод.
  12. Замерить время выполнения. Поставьте time перед командой.
  13. Псевдонимы для частых команд. В ~/.bashrc добавьте alias ll='ls -lah', затем выполните source ~/.bashrc.
  14. Строгий режим в скриптах. В начале bash-скрипта: set -euo pipefail. Скрипт остановится при первой ошибке и при обращении к неопределённой переменной.
  15. Переход между папками стеком. pushd /etc запоминает текущий каталог, popd возвращает назад.
  16. Сбросить кеш DNS в systemd-resolved. resolvectl flush-caches.
Команды kill -9, rm -rf, chmod -R и find ... -delete необратимы. Перед их запуском проверьте путь и условие, а для массовых операций сначала запустите то же самое без разрушающего действия.

Список рассчитан на Debian/Ubuntu и RHEL-подобные системы с systemd. Некоторые утилиты могут потребовать установки отдельно.
