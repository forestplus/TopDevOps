01 / TRACKING

Experiment tracking

Log parameters, metrics, tags and artifacts. Compare runs and make experiments reproducible rather than relying on notebook state.

02 / REGISTRY

Model lifecycle

Register model versions, associate them with source runs and manage promotion using explicit review and validation criteria.

03 / SERVING

Inference and serving

Package a model behind an HTTP interface, define resource requirements and validate latency, throughput and failure behavior.

04 / OPERATIONS

Observability & governance

Monitor service health, request errors, resource usage, model versions and artifact lineage. Protect credentials and isolate workloads.

RUN THE LAB

Quick start with Docker Compose.

The repository includes a starter stack. It is a local lab configuration, not a production-hardened deployment. Change credentials, restrict ports and configure durable backups before shared use.

cd v4/labs/mlflow
cp .env.example .env
# Set POSTGRES_PASSWORD in .env
docker compose up -d --build
docker compose ps
# MLflow UI: http://localhost:5000
docker compose logs -f mlflow
Open lab files & guide ↗docker-compose.yml

Lab roadmap

Bring up tracking + PostgreSQL → log a reproducible experiment → register a model → add model serving → add metrics and health checks → document backup, access control and upgrades.

The website does not host a live model endpoint. Run the Compose stack locally and treat sample data and default settings as non-production.
